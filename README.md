# TrukeGarai 

Auzokideen artean tresnak eta furgonetak alokatu, utzi edo trukatzeko aplikazioa. Etxeko gauzei errendimendua atera eta tokiko ekonomia zirkularra bultzatzeko sortua!

---

##  Zer da TrukeGarai?

TrukeGarai gure inguruko jendearekin tresnak partekatzeko plataforma bat da. Zerbaitek bereizten bagaitu, zera da: **katalogo berean aurkituko dituzula bai behar dituzun tresnak, bai horiek etxera eramateko ibilgailuak**.

**Bi aldeei laguntzen diegu:**
* **Erabiltzaileei:** Gauzak erosi edo etxean lekua hartzen ikusi ordez, unean uneko tresnak edo furgonetak merkeago lortzeko.
* **Jabeei:** Garajean hautsa hartzen ari diren tresnei modu seguruan diru pixka bat ateratzeko.

Aplikazioak katalogoa, argitalpen azkarrak egiteko aukera, txata eta profila ditu. Mapari eta iragazkiei esker, gertu dituzun gauzak ikusi, fitxa aztertu eta zuzenean erreserbatzen dituzu auzokideekin.

---

##  Nola gaude beste webgune batzuekin konparatuta?

Inguruan dauden beste aukeren onena hartu dugu eta dauzkaten hutsuneak konpondu ditugu:

* **Espezializatuta gaude:** Peerby bezalako web orokorren edo Bueydu bezalako makineria astuneko orrialdeen ordez, gu brikolajean eta etxeko lanetan zentratzen gara.
* **Erreserba azkarra eta automatikoa:** ShareTools bezalako tokietan txatetik edo deituz hitz egin behar da beti. Gurean, erreserba eta ordainketa % 100 automatikoak dira webgunean bertan.
* **Segurtasun osoa:** Kalteak izateko beldurra kentzeko, estaldura-asegurua eta kautzioen atxikipen automatizatua dugu.
* **Proiektuko Kitak:** Interfaze modernoa izateaz gain, proiektu zehatzetarako prestatutako tresna-kitak alokatzeko aukera daukazu (adibidez: "zorua jartzeko kita").

### Loturak:
* [Peerby](https://www.peerby.com/en-us)
* [Bueydu](https://bueydu.com/)
* [ShareTools](https://sharetools.es/agregar-herramienta)

##  Norentzat da? (Nortzuk gara?)

Gure erabiltzaile nagusia **brikolaje-zale eraginkorra** da:
* 28 eta 55 urte bitarteko pertsonak.
* Etxean edo lorategian noizean behin proiekturen bat egiten dutenak.
* Behin bakarrik erabiliko duten zerbaitetan dirua gastatu nahi ez dutenak.

### Zein arazo konpontzen dizkiogu?
*  **Beste web batzuetako arazoak:** Gauza gehiegi nahasita, orri konplexuak, txatetan denbora galtzea edo tresnak hondatzeko beldurra.
*  **Gure soluzioa:** Proiektukako kitak, erreserba eta ordainketa azkarrak, babes-asegurua eta plataforma oso erraz eta intuitiboa.
